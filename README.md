# Fake News Detector 📰

This is a **Streamlit app** that detects whether a news article or headline is **real or fake** using **Naive Bayes** and **TF-IDF vectorization**.

---

## Features

- Fast predictions using a pre-trained model
- Enter news text and get **Real/Fake** result instantly
- Shows **confidence percentage** of the prediction
- Attractive **faded background** and user-friendly interface
- No CSV files needed at runtime
